# ⏳ Pomo | Pomodoro Timer – Focus, Plan & Stay Motivated

A beautifully developed and well-designed Pomodoro Timer with integrated Todo list and automatic motivational quotes generation. Built with **Next.js**, **JavaScript**, **Tailwind CSS**, **React Icons**, and **Framer Motion** for smooth animations. Motivational quotes are fetched via **RapidAPI**, and the UI is fully responsive for all devices.

🔗 **Live Demo:** [https://pomodoro-timer-nine-olive.vercel.app](https://pomodoro-timer-nine-olive.vercel.app)

---

## 🚀 Features

- **Pomodoro Timer** – Focused work and break intervals.

- **Todo List** – Plan and track your tasks seamlessly.

- **Auto Motivation Quotes** – Fresh, inspiring quotes powered by RapidAPI.

- **Smooth Animations** – Elegant transitions with Framer Motion.

- **Responsive Design** – Perfectly optimized for mobile, tablet, and desktop.

- **Aesthetic UI** – Minimal yet visually pleasing interface.

## 📦 Installation

1. **Clone the repository**

```bash
git clone https://github.com/lachimolala2628/pomodoro_timer.git
```

2. **Install dependencies**

```bash
npm install
```

3. **Run development server**

```bash
npm run dev
```
